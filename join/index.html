参加方法

YuteneのMinecraftサーバーへ参加するための接続情報です。

Java Edition

マルチプレイからサーバーを追加して接続します。

  1. Minecraft Java Editionを起動し、「マルチプレイ」を開く。
  2. 「サーバーを追加」を選択する。
  3. サーバーアドレスに mc.yutene.net を入力して接続する。
