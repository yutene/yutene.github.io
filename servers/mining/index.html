MINING SERVER

採掘サーバー

鉱石を掘って成長していく、採掘中心のゲーム型サーバーです。

ABOUT

採掘そのものをゲームに

普通のサバイバルとは別に、採掘・成長・強化を中心に進めるサーバーです。

採掘

鉱石を掘り、売却しながら進行します。より効率よく掘れるように装備を強化していく構成を予定しています。

成長

レベル、EXP、専用ピッケルなど、採掘を続けるほど成長を感じられるシステムを予定しています。

クエスト

デイリー・ウィークリーなどの課題要素を追加予定です。具体的な内容や報酬は制作時に調整します。

独自要素

採掘向けの強化やエンチャントなどを検討しています。細かな仕様は今後決定します。
