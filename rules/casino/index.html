SERVER RULES / CASINO

Casino

Yutene全体ルールに加えて、Casinoでは以下の固有ルールが適用されます。

ゲーム内通貨

  • Casinoで使用するのはYutene Serverと共有しているゲーム内通貨です。
  • ゲーム内通貨・アイテムを現実の金銭等と交換する行為は禁止です。

不具合の悪用

  • 配当、賭け金、GUI、同期などの不具合を意図的に悪用する行為は禁止です。
  • 異常な挙動を見つけた場合は、繰り返し利用せず運営へ報告してください。

残高・結果

  • 正常に処理されたゲーム結果・配当は原則としてその結果を採用します。
  • 障害や明確な不具合が確認された場合、運営が残高や結果を修正する場合があります。
