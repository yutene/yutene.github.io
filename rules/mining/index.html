SERVER RULES / MINING

採掘サーバー

Yutene全体ルールに加えて、採掘サーバーでは以下の固有ルールが適用されます。

基本方針

採掘、売却、成長、装備強化などを中心に遊ぶゲーム型サーバーです。通常のプレイやプレイヤー同士の取引は尊重しつつ、進行を不正に飛ばす行為を禁止します。

採掘・横取り

  • 他プレイヤーが採掘したアイテムを故意に横取りする行為は禁止です。
  • 他プレイヤーの採掘を継続的・故意に妨害する行為は禁止です。

不正な採掘

  • Xray、マクロ、Freecam、Baritoneなど、採掘や進行を不正に有利にする機能の使用は禁止です。
  • バグや設定ミスを利用して、お金、EXP、アイテム等を異常に取得する行為は禁止です。
  • 運営が用意した進行・強化システムを不具合等で意図的に回避する行為は禁止です。

アイテムの受け渡し

  • 通常の取引や少量のプレゼントは許可されています。
  • 大量の通貨・高性能装備・大量アイテムの配布など、他プレイヤーの進行を大きく飛ばす目的の配布は禁止です。

処分

違反への対応は固定の処分表ではなく、行為の内容や影響を確認したうえで運営が決定します。
