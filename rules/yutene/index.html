SERVER RULES / MAIN

Yutene Server

Yutene全体ルールに加えて、このサーバーでは以下の固有ルールが適用されます。

基本方針

生活・経済を中心に遊ぶメインサーバーです。AFKやサーバー内で完結する自動化は広く許可し、盗難・他人への直接的な迷惑行為・不正クライアントなどを禁止します。

盗難

  • 他人の所有物を無断で持ち出す行為は禁止です。
  • 保護の有無だけを理由に、明らかに他人の物を自由に持ち出してよいものとはしません。

プレイヤーへの攻撃

  • 他プレイヤーを故意に殺害・妨害する行為は禁止です。
  • 溶岩、窒息、装置などを利用した間接的な殺害も同様です。

クライアント・自動化

  • Xray、マクロ、Freecam、Baritoneなど、不正な優位を得る目的の機能は禁止です。
  • AFKは許可されています。
  • レッドストーン、農場、トラップなど、サーバー内で完結する自動化は原則許可されています。
  • 外部マクロによる自動操作は、自動化とは別扱いで禁止です。

経済・Casino

  • Yutene ServerとCasinoは同じゲーム内残高を共有します。
  • ゲーム内通貨やアイテムを、現実の金銭等と交換する行為は禁止です。
  • 経済・カジノ機能の不具合や抜け道を意図的に悪用する行為は禁止です。

複数アカウント

  • 複数アカウントでの参加自体は許可されています。
  • BAN、Timeoutその他の制限を回避する目的で利用することは禁止です。
