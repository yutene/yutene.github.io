SERVER RULES / MAIN

Yutene Server

Yutene全体ルールに加えて、このサーバーでは以下の固有ルールが適用されます。

基本方針

Towny・経済・Jobs・MCMMOなどを使って遊ぶメインサーバーです。AFK・自動化・市場競争は広く許可し、他人への直接的な迷惑行為や不正クライアントを制限します。

盗難

  • 盗難は禁止です。
  • ClaimやBoltによる保護の有無に関係なく、明らかに他人の所有物を無断で持ち出してはいけません。

Claim外・プレイヤーへの攻撃

  • Claim外の建築・地形は原則として保護対象外です。採掘、整地、破壊などは許可されます。
  • PvPはOFFです。
  • 溶岩などを利用して他プレイヤーを故意に殺害する行為は禁止です。

クライアント・自動化

  • Xray、マクロ、Freecam、Baritoneの使用は禁止です。
  • AFKは許可されています。
  • レッドストーン、農場、トラップなど、サーバー内で完結する自動化は原則すべて許可されています。
  • 外部マクロによる自動操作は、自動化とは別扱いで禁止です。

Towny

  • Towny戦争はありません。
  • TownはTownyの日次処理などによって正式に崩壊しない限り、長期間の放置だけを理由に運営が削除することはありません。

QuickShop

  • 転売、値下げ、値上げ、価格競争など、通常の市場活動はすべて許可されています。
  • 価格は各プレイヤーが自由に決められます。

Jobs・複数アカウント

  • Jobsは最大3つまで所属できます。
  • 複数アカウントでの参加は許可されています。
  • その他のTowny・Jobs等の細かな設定値は、サーバー仕様として別途案内します。
