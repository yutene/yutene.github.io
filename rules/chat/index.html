SERVER RULES / CHAT

雑談サーバー

通常時は閉鎖されており、不定期で開放される交流用サーバーです。

開放について

  • 雑談サーバーは常時開放ではありません。
  • 開放日時は、その都度Yuteneから案内します。
  • 閉鎖中は参加できません。

ルール

  • Yutene全体ルールが適用されます。
  • 開放内容に応じて追加ルールがある場合は、その都度案内します。
