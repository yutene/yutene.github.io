SERVER RULES / SAGYOCHU

sagyochu

サバイバル・PvP ON。チート以外は基本的になんでもOKの高自由度サーバーです。

基本方針

sagyochuは高自由度のサバイバルサーバーです。チート行為を除き、ゲーム内の行為は基本的に許可されています。

許可されていること

  • PvPはONです。
  • AFK、自動化、大規模装置、TNT、溶岩、火、地形破壊などは許可されています。
  • グリッチ、複製、特殊装置なども基本的に許可されています。
  • Litematica、Freecamなどの補助機能も利用できます。

禁止事項

  • 不正クライアント等を利用したチート行為は禁止です。
  • Xray、KillAura、Fly、Speed、Baritone等による不正な自動操作・能力の利用は禁止です。
