プライバシーポリシー

Yuteneにおける利用者情報の取得・利用・保存について定めています。

最終更新日：2026年9月13日

ゆてね（以下「運営」といいます。）は、Minecraftサーバー、Webサイト「yutene.net」およびこれらに関連するサービス（以下「本サービス」といいます。）における利用者に関する情報を、本プライバシーポリシーに従って取り扱います。

第1条　取得する情報

Minecraftサーバー利用時

  • Minecraft ID
  • UUIDその他アカウントを識別するための情報
  • Bedrock Edition利用時の識別情報
  • IPアドレス
  • 接続日時
  • 接続しているサーバー
  • チャット内容
  • 使用したコマンド
  • プレイ履歴
  • ゲーム内所持金
  • インベントリ等のゲームデータ
  • 権限情報
  • Kick、BAN、Timeoutその他の処分履歴
  • 不正行為・セキュリティ対策・障害調査に必要な各種ログ

Webサイト利用時

  • アクセス日時
  • 閲覧したページ
  • 参照元
  • ブラウザ・OS等の端末に関する情報
  • Webサイトの表示・パフォーマンスに関する情報
  • その他アクセス解析サービスによって統計的に処理される情報

申請・問い合わせ時

  • Minecraft ID
  • 利用者が入力した名前またはニックネーム
  • 連絡先
  • 申請内容
  • 問い合わせ内容
  • その他利用者が任意に送信した情報

運営は、本サービスの利用に必要のない本名、住所、電話番号等の情報を、不必要に利用者へ要求しないよう努めます。

第2条　利用目的

  1. 本サービスを提供・維持するため
  2. Minecraftサーバーへの接続および利用者識別のため
  3. Whitelistその他のアクセス管理を行うため
  4. プレイヤーデータを保存するため
  5. ゲーム内経済、権限その他の機能を提供するため
  6. 不正行為、荒らし、チートその他の規約違反を検出・調査するため
  7. Kick、BAN、Timeoutその他の管理措置を実施するため
  8. 利用者同士のトラブルを調査するため
  9. サーバーおよびWebサイトへの攻撃、不正アクセス等を防止するため
  10. 障害、不具合等を調査するため
  11. バックアップおよびデータ復旧を行うため
  12. 利用状況を把握し、本サービスを改善するため
  13. 利用者からの問い合わせへ回答するため
  14. 重要なお知らせを行うため
  15. 法令上必要な対応を行うため

第3条　サーバーログの保存

本サービスでは、安全管理、不正行為への対応、トラブル解決、障害調査、処分履歴の確認等を目的として、以下の情報をサーバーログとして保存する場合があります。

  • 接続・切断記録
  • IPアドレス
  • Minecraft ID・UUID
  • チャット
  • コマンド
  • サーバー移動
  • 処分履歴
  • ゲーム内操作に関する記録
  • その他運営・セキュリティ上必要な記録

これらのサーバーログは、原則として保存期間を定めず保存する場合があります。

ただし、運営上不要となった情報は削除・整理する場合があります。

第4条　バックアップ

運営は、データ消失や障害に備えるため、本サービスのデータをバックアップする場合があります。削除済みの情報がバックアップ内に残る場合があります。

第5条　第三者への提供

運営は、次の場合を除き、取得した個人情報を第三者へ提供しません。

  1. 本人の同意がある場合
  2. 法令に基づく場合
  3. 人の生命、身体または財産の保護のために必要な場合
  4. 不正アクセスその他重大な違法行為への対応として必要な場合
  5. 本サービスの提供に必要な範囲で業務委託先へ取り扱いを委託する場合
  6. その他法令で認められている場合

第6条　外部サービス

本サービスでは、サーバーへの接続、インフラ、セキュリティ、アクセス解析その他の機能を提供するため、第三者のサービスを利用する場合があります。

  • Microsoft / Mojangが提供するMinecraft関連サービス
  • Playit等のネットワーク中継サービス
  • Webサーバー、DNS、ドメイン関連サービス
  • Cloudflare Web Analytics
  • その他本サービスの提供に必要なインフラサービス

各外部サービスが独自に取得・処理する情報については、それぞれのサービス提供者のプライバシーポリシー等が適用されます。

第7条　アクセス解析

本サイトでは、サイトの利用状況およびパフォーマンスを把握し、サービスを改善するため、Cloudflare Web Analyticsを使用する予定です。

ページの閲覧状況、参照元、使用端末、ブラウザ、パフォーマンス情報等の統計情報が処理される場合があります。

取得した統計情報は、本サイトの利用状況の把握、表示速度の改善、コンテンツの改善その他本サービスの運営改善のために利用します。

第8条　Cookie等

本サイトでは、サイトの動作、設定保存、セキュリティ等に必要なCookieその他の技術を使用する場合があります。

新たに広告サービス、追加のアクセス解析サービスその他利用者情報を外部へ送信するサービスを導入する場合は、必要に応じて本ポリシーまたはサイト上でその内容を明示します。

第9条　情報の安全管理

運営は、取得した情報について、不正アクセス、漏えい、紛失、改ざん等を防止するため、必要かつ合理的な安全管理措置を講じます。

  • 管理情報へのアクセス権限の制限
  • 管理アカウントの認証
  • サーバーおよびソフトウェアの更新
  • 不正アクセス対策
  • バックアップ

第10条　情報の開示・訂正・削除等

利用者は、法令に基づき、自身に関する情報について開示、訂正、利用停止、削除等を請求できる場合があります。希望する場合は、下記のお問い合わせ先からご連絡ください。

本人確認が必要となる場合があります。また、法令、セキュリティ、BAN回避防止その他正当な理由により、一部の情報を削除できない場合があります。

第11条　未成年者の情報

未成年者が個人情報等を送信する場合は、必要に応じて保護者その他の法定代理人の同意を得てください。運営は、サービス提供上必要のない詳細な個人情報を未成年者から積極的に収集しないよう努めます。

第12条　本ポリシーの変更

運営は、サービス内容、使用するシステム、法令等の変更に応じて、本プライバシーポリシーを変更する場合があります。重要な変更については、本サイトその他適切な方法で告知します。
